# موقع معرض الأعمال

موقع ثابت يُنشر مجانًا على **GitHub Pages**، مع لوحة تحكم تحفظ التعديلات مباشرة في GitHub دون الحاجة إلى خادم.

## طريقة العمل
- ملفات الموقع كلها في مجلد `docs/`، والمحتوى في `docs/content.json`.
- لوحة التحكم على الرابط `/admin/` تتصل بحسابك في GitHub عبر «رمز دخول» (Token).
- كل عملية حفظ تُسجَّل نسخةً في GitHub، ويُحدَّث الموقع تلقائيًا خلال دقيقة تقريبًا.
- الصور والفيديوهات المرفوعة تُحفظ في `docs/uploads/`.
  - **حد الصورة:** 25 ميجابايت.
  - **حد الفيديو:** 70 ميجابايت.
  - **الفيديوهات الأكبر:** استخدم روابط يوتيوب أو إنستغرام أو تيك توك.

## النشر لأول مرة
1. **أنشئ حسابًا** على [github.com](https://github.com) إن لم يكن لديك حساب.
2. **أنشئ مستودعًا جديدًا** من [github.com/new](https://github.com/new):
   - **الاسم:** مثلًا `portfolio`.
   - **النوع:** **Public** (عام)، لأن GitHub Pages المجاني يتطلب ذلك.
   - **الإعدادات الأخرى:** لا تضف أي ملفات (لا README ولا غيره).
3. **ارفع الملفات** إلى المستودع (الأوامر في القسم التالي).
4. **فعّل الاستضافة:** من المستودع افتح **Settings ← Pages**، ثم اختر:
   - **Source:** Deploy from a branch.
   - **Branch:** `main`، والمجلد `/docs`، ثم اضغط Save.

   بعد دقيقة أو دقيقتين يصبح موقعك على الرابط:
   `https://اسم-المستخدم.github.io/portfolio/`
5. **أنشئ رمز الدخول للوحة التحكم** من [github.com/settings/personal-access-tokens/new](https://github.com/settings/personal-access-tokens/new):
   - **Token name:** لوحة تحكم الموقع.
   - **Expiration:** المدة التي تناسبك (يمكن تجديده لاحقًا).
   - **Repository access:** Only select repositories، واختر مستودع الموقع فقط.
   - **Permissions ← Repository permissions ← Contents:** Read and write.
   - اضغط Generate token، ثم انسخ الرمز.
6. **ادخل لوحة التحكم** من `https://اسم-المستخدم.github.io/portfolio/admin/`:
   - يتعرّف اسم المستخدم والمستودع تلقائيًا.
   - الصق رمز الدخول، ثم اضغط «ربط وتسجيل الدخول».

## رفع الملفات (الخطوة 3)
من داخل مجلد المشروع:

```bash
git remote add origin https://github.com/اسم-المستخدم/portfolio.git
git push -u origin main
```

ستفتح نافذة لتسجيل الدخول إلى GitHub عند أول رفع.

## المعاينة على الجهاز
دبل كلك على **«تشغيل الموقع.bat»** لمعاينة الملفات الموجودة على جهازك. التعديلات الفعلية تتم من لوحة التحكم على الموقع المنشور، لأنها تحفظ في GitHub مباشرة.

## الخط
يستخدم الموقع «خط ثمانية» إذا كان مثبتًا على جهاز الزائر، وإلا يستخدم IBM Plex Sans Arabic. ترخيص خط ثمانية لا يسمح برفع ملفاته على المواقع؛ لاستخدامه للجميع راسل ثمانية على Ask@thmanyah.com.

## الأمان
- رمز الدخول يُحفظ في متصفحك فقط، ويُحذف عند تسجيل الخروج.
- اجعل صلاحية الرمز مقتصرة على مستودع الموقع فقط.
- إذا فقدت جهازك أو شككت في تسرّب الرمز، احذفه من إعدادات GitHub وأنشئ رمزًا جديدًا.
